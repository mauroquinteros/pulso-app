# Triage Labels

This repo does **not** use triage labels.

When a skill (e.g. `triage`) references a canonical triage role — `needs-triage`,
`needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix` — do **not** apply
any label or `Status:` marker to issue files. Skip the labelling step entirely.

If you later decide to adopt triage states, map the five roles to label/status
strings here and update `CLAUDE.md` accordingly.
